## Request Processing Pipeline

```
Request arrives at Kestrel
    ?
Program.cs middleware pipeline
    ?? HTTPS redirection
    ?? ExceptionsMiddleware (rate limiting, security headers)
    ?? Authorization middleware
    ?? Routing
        ?
Controllers (ProductsController, etc.)
    ?? Inject IUnitOfWork, IMapper
    ?? Parse request DTO (AddProductDto, etc.)
    ?? Call repository method
    ?   ?
    ?   ProductRepository.AddAsync(dto)
    ?       ?? Map DTO ? Domain Entity
    ?       ?? Save to database
    ?       ?? Call ImageManagementService
    ?       ?? Return result
    ?
    ?? Map Domain ? Response DTO
        ?? Return IActionResult (200 OK, 404 NotFound, etc.)
    ?
Response sent to client (JSON)
```

---

This architecture ensures:
- **Clean Code** - Each layer has single responsibility
- **Easy Testing** - Mock interfaces, not implementations
- **Easy Maintenance** - Find code quickly
- **Easy Extension** - Add features following same pattern
- **Enterprise Ready** - Scales to large applications
